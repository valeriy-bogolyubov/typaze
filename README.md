# typaze

Тренажёр печати на русском и английском языках. После теста можно посмотреть, где возникали ошибки, потренировать сложные сочетания и проверить результат на новом тексте.

[Открыть typaze](https://valeriy-bogolyubov.github.io/typaze/)

## Режимы

| Режим | Что можно делать |
| --- | --- |
| Тест | Проверить скорость и точность за 30 или 60 секунд. |
| Свободно | Печатать без ограничения времени, делать паузы и завершать занятие самостоятельно. |
| По моим ошибкам | Отрабатывать символы и сочетания, с которыми чаще возникают трудности. Рекомендации появляются, когда накоплено достаточно результатов. |
| Обучение | Пройти шесть упражнений: опорные клавиши, основной, верхний и нижний ряды, слова и предложения. |

Язык интерфейса и язык упражнений разделены. В настройках можно изменить размер текста и уменьшить движение элементов, а во время занятия включить экранную клавиатуру.

## Сохранение и перенос истории

История, настройки и прогресс курса хранятся в `localStorage` текущего браузера. В истории остаются последние 100 занятий.

Чтобы перенести результаты в другой браузер или на другое устройство:

1. Откройте «Настройки» и нажмите «Скачать историю».
2. Сохраните полученный JSON-файл.
3. На другом устройстве откройте typaze, выберите «Восстановить из файла» и проверьте сводку перед подтверждением.

При восстановлении записи объединяются с текущей историей. 

## Локальный запуск

Нужен Node.js версии =>22 и npm.

```sh
git clone https://github.com/valeriy-bogolyubov/typaze.git
cd typaze
npm run dev
```

Откройте [http://127.0.0.1:5173](http://127.0.0.1:5173).

## Как устроен проект

Интерфейс написан на HTML, CSS и JavaScript.

| Файлы | Назначение |
| --- | --- |
| `index.html`, `app/styles.css` | Разметка и оформление интерфейса. |
| `app/main.js` | Управление занятиями, экранами и действиями пользователя. |
| `app/engine.js` | Сопоставление введённого текста с исходным, состояния попытки и расчёт показателей. |
| `app/content.js`, `app/curriculum.js` | Тексты для практики и упражнения курса. |
| `app/result-analysis.js`, `app/result-review.js` | Аналитика и разбор ошибок в тексте. |
| `app/storage.js`, `app/progress-state.js`, `app/backup.js` | Сохранение результатов, прогресс курса и перенос истории. |
| `app/i18n.js`, `app/language.js` | Переводы интерфейса и выбор языка. |

В интерфейсе используется шрифт JetBrains Mono. Он распространяется под [лицензией SIL Open Font License 1.1](assets/OFL.txt), которая расположена в `assets/`.
